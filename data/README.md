# Publication run data

This directory contains the small, redistributable inputs and environment
metadata referenced by the standalone workflows. Both JSON configurations
resolve repository-relative paths from their own `configs/` directories.

## Contents

| Directory | Asset | Original source |
|---|---|---|
| `lincs/`, `tox21/`, `ceviche/`, `models/` | Optional local inputs when present; large files are intentionally external to this release | Original acquisition paths are recorded in the workflow configs/provenance |
| `environments/` | Explicit Conda package specifications | Local `crisp_env` and `crisp_chemprop_env` environments |

`SHA256SUMS` records files actually bundled in this directory. Validate with:

```bash
sha256sum --check SHA256SUMS
```

## Deliberately external or generated paths

The chemical config retains an absolute `inputs.chemprop_python` path. A
Python executable cannot be made portable by copying the binary alone because
it depends on its complete Conda prefix. Recreate that environment from
`environments/crisp_chemprop_env_explicit.txt`, then update the config if its
prefix differs.

The following biological inputs are generated by the preceding chemical
workflow under `generated/molecular_prediction_and_ensemble/`:

- `cohort_dir`
- `stage1_split`
- `chem_offset`

Run the complete chemical workflow before validating or running the
biological workflow. Biological outputs are written under
`generated/transcriptomic_residual_learning/`.

## Integrity and provenance

The pre-release copies of large runtime assets are recoverable under the
ignored `backup/publication_pre_release_20260902/large_runtime_assets/` tree;
they are excluded from the public package because they are too large or
redistribution-restricted. The standalone launchers refuse missing inputs and
existing enabled-stage output directories before fitting.
