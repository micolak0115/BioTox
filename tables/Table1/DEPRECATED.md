# Deprecated publication asset

`Table1_source_data.csv` and `Table1_display.csv` are deprecated legacy
assets. They are not the manuscript's Table 1 and must not be used as inputs
for reproduction, validation, or regenerated publication results.

The manuscript's Table 1 is the qualitative Tox21--LINCS context-correspondence
table embedded in the manuscript source under
`tab:tox21-lincs-configurations`. Context-specific performance results belong
to the current Table S9 / Figure 3 analysis outputs.

Reason for deprecation: these files contain values from an older publication
summary and are not provenance-compatible with the current standalone
`primary_6h` and `paired_24h` runs.
